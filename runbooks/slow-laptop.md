# Laptop is slow

**Priority:** P3.

1. Ask when it started and what changed: new software, a recent update, a full disk.
2. Check free disk space, memory use and start-up programs in Task Manager.
3. Check for pending updates and restart the device (many "slow" tickets are a laptop not restarted for weeks).
4. Scan for unwanted software. A suspected infection is **P1 security**: isolate and escalate.
5. If hardware is the cause (old drive, little RAM), raise a replacement request.
