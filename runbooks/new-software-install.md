# Software installation request

**Priority:** P3 (standard procedure, no escalation needed for approved software).

1. Confirm the software is on the approved list and that the user's manager has approved the licence.
2. Install from the company software source, never from a random download site.
3. Configure the standard settings and test that it opens and saves a file.
4. Record the version and licence in the ticket, then ask the user to confirm and close the ticket.
